1. Executive Summary & Product Vision

Trading Journal Pro dirancang untuk menjadi "Linear / Discord for Financial Traders". Platform ini bukan sekadar arsip statis untuk mencatat histori transaksi, melainkan sistem operasi harian bagi trader untuk mencatat perjalanan posisi secara live (timeline updates), memantau risiko secara real-time, mengidentifikasi kebocoran strategi (strategy leaks), dan menumbuhkan disiplin eksekusi melalui visualisasi data modern berestetika tinggi.

Masalah Utama yang Diselesaikan:
  • Catatan Tercecer: Jurnal di Excel/Notion kaku, lambat diakses, dan tidak memiliki kalkulasi metrik otomatis.
  • Kehilangan Konteks Emosi & Timeline: Saat trade berlangsung, trader panik atau overthinking karena tidak ada pencatatan perjalanan posisi bertahap.
  • Statistik Manual: Sulit mengetahui Win Rate mingguan, Average RR, jam entry paling profitable, dan pair terbaik secara cepat.
  • Persiapan Otomasi: Trader ingin jurnal yang hari ini bisa dipakai manual secara instan, namun arsitekturnya siap dicolok ke MT5 dan AI.

2. User Persona

Raihan (Primary User — Discretionary SMC Trader)

  • Instrumen Utama: XAUUSD (Gold) dan Major FX (EURUSD, GBPUSD).
  • Metodologi: Smart Money Concepts (SMC - Break of Structure, Liquidity Sweep, Order Block, FVG) dipadukan dengan Key Support & Resistance (Timeframe M5 & M15).
  • Platform: MetaTrader 5 (MT5 Desktop & Mobile).
  • Pain Points: Sering lupa alasan entry setelah posisi tertutup; kesulitan mengukur konsistensi Risk-to-Reward (RR); ingin jurnal yang estetik seperti social feed Discord/X.

6. Database Design (MySQL DDL Specification)

Tabel: users

FieldTypeKeterangan

nameVARCHAR(100)Nama pengguna
emailVARCHAR(150) (UNIQUE)Email akun
passwordVARCHAR(255)Hashed password (bcrypt)
initial_balanceDECIMAL(15,2)Saldo awal akun trading (default $10,000)

Tabel: trades

FieldTypeKeterangan
idBIGINT UNSIGNED (PK)Trade ID unik
user_idBIGINT UNSIGNED (FK)Relasi ke tabel users.id

entry_priceDECIMAL(15,5)Harga eksekusi awal
sl_priceDECIMAL(15,5)Harga Stop Loss
tp_priceDECIMAL(15,5)Harga Take Profit
exit_priceDECIMAL(15,5) (NULL)Harga saat posisi ditutup
lotDECIMAL(8,2)Ukuran lot
timeframeVARCHAR(10)M1, M5, M15, H1, H4, D1
sessionVARCHAR(30)Asian, London, New York
reasonTEXTAlasan entry (SMC, S/R, Trend, dsb)
statusENUMOPEN, CLOSED_TP, CLOSED_SL, CLOSED_BE, CLOSED_MANUAL

profit_moneyDECIMAL(15,2)Hasil PnL dalam mata uang USD

screenshot_afterVARCHAR(255)File path screenshot setelah exit

closed_atDATETIMEWaktu posisi ditutup

FieldTypeKeterangan

current_priceDECIMAL(15,5)Harga saat update dibuat
floating_pointsDECIMAL(12,2)Jarak point floating profit/loss

9. Future Killer Feature: AI Coach & MT5 Architecture

🤖 AI Trading Coach (Phase 3)

Setelah trade ditutup, sistem dapat mengirimkan parameter entry, exit, reason, dan gambar chart ke LLM (OpenAI/Gemini) untuk evaluasi otomatis:

"Entry Buy di support M5 sesuai dengan plan BOS. Exit di TP menghasilkan RR 1:2.8. Catatan: Entry sangat disiplin, namun Stop Loss sebesar 52 point sedikit terlalu lebar untuk M5; Anda bisa mempersempit SL tepat di bawah liquidity sweep wick untuk mendongkrak RR menjadi 1:4."

⚡ MetaTrader 5 (MT5) Auto-Bridge

Arsitektur API telah dirancang dengan endpoint /api/v1/integrations/mt5. Sebuah script Expert Advisor (MQL5) atau Python script dapat mengirimkan posisi saat terbuka dan menutup secara otomatis tanpa perlu mengubah struktur database yang ada.
